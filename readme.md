# База данных «Маршруты БПЛА»

Учебный проект по проектированию реляционной базы данных для учета полетов беспилотных воздушных судов (БВС).

## 📌 Описание предметной области
База данных предназначена для хранения информации о парке БВС, готовых шаблонах маршрутов, путевых точках и журнале фактических полетов. 
Структура приведена к 3-й нормальной форме (3НФ) и исключает дублирование данных.

## 🗄️ Структура БД (4 таблицы)
1. **Drones** — справочник дронов (модель, серийный номер).
2. **Routes** — справочник маршрутов (шаблоны миссий).
3. **Waypoints** — точки маршрутов (координаты, высота, скорость, действие).
4. **Flights** — журнал полетов (связывает дрон, маршрут, дату и оператора).

## 🚀 Как развернуть базу (phpMyAdmin / MySQL)
1. Создайте базу данных (например, `uav_db`).
2. Откройте вкладку SQL.
3. Скопируйте содержимое файла `database.sql` из этого репозитория и нажмите «Выполнить».

## 🛠️ Технологии
* MySQL / MariaDB (InnoDB)
* phpMyAdmin
